# Scratch Learning Projects

A growing collection of Scratch projects and SVG artwork for learning programming step by step: games, animations, and small experiments that each introduce one or two new ideas.

These files accompany my posts on Substack, where I walk through how each project is built: https://ai4kids.substack.com.

## What's inside

```
projects/
  01-project-name/
    project-name.sb3      ← the Scratch project
    preview.png           ← screenshot
    sprites/              ← SVG sprites and backdrops used in the project
      character.svg
      backdrop.svg
  02-project-name/
    ...
```

Each project folder holds the `.sb3` file, a preview image, and the SVG assets, so you can either open the whole project or reuse individual sprites in your own work.

## How to open a project

**In the browser (no install needed)**
1. Download the `.sb3` file: open it on GitHub and click the **Download raw file** button.
2. Go to [scratch.mit.edu/projects/editor](https://scratch.mit.edu/projects/editor/).
3. Choose **File → Load from your computer** and select the `.sb3` file.

You can also open `.sb3` files in [TurboWarp](https://turbowarp.org/editor), a faster Scratch-compatible editor, or in the offline [Scratch app](https://scratch.mit.edu/download).

**To get everything at once**, click the green **Code** button at the top of this page and choose **Download ZIP**.

## Using the SVG files

The SVGs open in any browser and can be edited in Inkscape, Figma, or Illustrator. To use one in Scratch, open the **Costumes** (or **Backdrops**) tab, hover over the cat icon at the bottom left, and choose **Upload**.

## Who this is for

- Kids learning to code, and the parents or teachers helping them
- Anyone curious about Scratch who prefers learning by building something real

Each project is small enough to finish in one sitting, and later projects build on ideas from earlier ones.
